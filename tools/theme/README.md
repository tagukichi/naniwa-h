# NANIWA EXPRESS テーマ セットアップ手順

なにわ引越センター公式サイト用のオリジナルテーマ（クラシックテーマ）です。
静的HTMLで確定したデザインをそのまま移植しています。

---

## 0. テーマをアップした後にやること（作業チェックリスト）

上から順に進めてください。所要 15〜20分程度です。

### ① テーマを有効化

**外観 → テーマ → 新規追加 → テーマのアップロード** で ZIP を入れて「有効化」。

### ② パーマリンクを再構築

**設定 → パーマリンク** を開いて、何も変えずに「変更を保存」。
お客様の声 `/voice/` とお知らせ `/topics/` のURLがこれで有効になります。

### ③ 固定ページの割り当て

**ツール → なにわ：初期設定** を開く。

- 23ページの割り当て状況が一覧で出ます
- 「✗ 404」の行があれば **「見つからない N 件のページを新規作成する」** を押す
- 意図と違うページが割り当たっていたら、右の欄で手動指定して「割り当てを保存する」

> スラッグが違っていても自動で探します（`estimate-step1` → `step1` など）。
> 見積の荷物ページだけは既存の `step6-1〜3` と別物なので、新規作成が必要です。

### ④ ブログの投稿ページを設定

**設定 → 表示設定**

- ホームページの表示：**固定ページ**
- ホームページ：**選択しない**（TOPは `front-page.php` が使われます）
- 投稿ページ：**ブログ**（無ければ先に固定ページを作る）

### ⑤ 求人フォームをつなぐ

**外観 → カスタマイズ → なにわ：フォーム設定** に、Contact Form 7 の
ショートコードを貼り付けて公開。

```
[contact-form-7 id="361b20a" title="求人用フォーム"]
```

### ⑥ SMTPパスワードを入れ直す（サイトを移設したときは必須）

**WP Mail SMTP → 設定 → 一般** で、SMTPパスワードを入力し直して保存。
**ツール → メールテスト** が通ることを確認します。

> 移設のときに見落としやすい箇所です。
> WP Mail SMTP はパスワードを暗号化して保存していて、その復号キーは
> `wp-config.php` の認証キー（ソルト）に紐づいています。
> All-in-One WP Migration などでDBを移すと、暗号文だけが移ってキーは
> 移設先の別のものになるため、**画面上は `●●●●` と入っているように見えるのに
> 復号できず**、`SMTP Error: Could not authenticate.` になります。
> 入力し直す以外に直す方法はありません。

### ⑦ 見積フォームのテスト送信

STEP1 から最後まで通して送信し、次の3つを確認します。

- 管理者宛にメールが届く
- 入力したアドレス宛に自動返信が届く
- **web見積の送信** に記録が残っている（「メール送信」列が両方 ✓）

> 送信内容はメールとは別にDBへ保存しているので、メールが届かなくても
> 内容は失われません。原因は記録の編集画面「メールの送信結果」に出ます。

### ⑧ 表示確認

TOP／単身の引越／求人情報／お客様の声一覧・詳細／お知らせ／ブログを一通り開く。
スマホ表示もあわせて確認。

### ⑨ 旧CF7フォームの整理（確認が済んでから）

見積が問題なく動いたら、CF7 の **STEP1〜STEP7・step6-1〜3・確認** を削除。
**求人用フォームは残します。**
不要になった固定ページ（`step6-1` `step6-2` `step6-3` など）も削除して構いません。

## 1. インストール

1. WordPress 管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**
2. `naniwa-express.zip` を選択して「今すぐインストール」→「有効化」

必要環境：WordPress 6.0 以上／PHP 7.4 以上

---

## 2. 固定ページの割り当て

このテーマはページごとに専用テンプレート（`page-{スラッグ}.php`）を持っています。
**スラッグが想定と違っていても自動で対応するページを探す**ので、
既存サイトから引き継いだページ名のままでも動きます。

自動判定の順序：

1. 管理画面で手動割り当てされていればそれ
2. 想定スラッグと完全一致するページ（ルート直下）
3. `estimate-` を外したスラッグ（`estimate-step1` → `step1`）
4. 階層を無視したスラッグ検索（親ページの下に作られていても拾います）
5. 連番が付いたスラッグ（`recruit` → `recruit2` / `recruit-2`）

### ページを作ったのに404になるとき

初期設定画面の「状態」列を確認してください。

- **下書きのまま** … 公開しないと 404 になります。「編集」から公開してください
- **✗ ページなし** … スラッグが違います。手動割り当てで指定するか、作成ボタンで新規作成してください
- **親ページの下にあります** … URLが `/親/子/` になります。リンクは自動追従するので問題ありませんが、意図と違う場合は親を外してください

### 確認と設定

**ツール → なにわ：初期設定** を開いてください。

- 必要な25ページそれぞれについて、**どのページが割り当たっているか**が一覧で見えます
- 見つからないものは「✗ 404」と表示されます
- 「見つからない N 件のページを新規作成する」でまとめて作成できます
- 意図と違うページが割り当たっている場合は、右の欄で**手動で指定**できます

> 日本語タイトルのまま固定ページを作るとスラッグも日本語になります。
> 自動判定では拾えないので、その場合は手動割り当てを使ってください。

想定スラッグ一覧：

`single` `family` `couple` `now` `office` `disused` `flow` `packing` `others`
`faq` `checklist` `company` `kiyaku` `recruit`
`estimate-step1`〜`estimate-step5` `estimate-items`（荷物）
`estimate-step7` `estimate-confirm` `estimate-thanks`

### ブログ

ブログ用に固定ページを1つ（例：スラッグ `blog`）作り、
**設定 → 表示設定** で以下を指定してください。

- ホームページの表示：**固定ページ**
- ホームページ：（指定しない ＝ フロントページ用テンプレートが使われます）
- 投稿ページ：**ブログ**

## 3. 投稿タイプ

| 種類 | 投稿タイプ | 一覧URL |
|---|---|---|
| ブログ | 投稿（標準） | 上記「投稿ページ」に設定したURL |
| お知らせ | `topics` | `/topics/` |
| お客様の声 | `voice` | `/voice/` |

投稿タイプは **ACF が登録済みならテーマ側では登録しません**。
ACF を使わない環境ではテーマが同じ設定で登録するので、どちらでも動きます。

### お客様の声の入力項目（ACF）

旧サイトの ACF フィールドをそのまま使います。

| フィールド名 | ラベル | 用途 |
|---|---|---|
| `rating` | 評価画像 | 顔アイコンと★の判定（1〜5） |
| `kinds` | 引越の種別 | 単身の引越／ご家族の引越 など |
| `grade` | グレード | スタンダード など |
| `place` | 地域 | 磯子区→中区 |
| `introduction` | 冒頭文章 | 一覧カードの本文 |
| `age` / `gender` | 年代 / 性別 | 一覧・詳細の属性表示 |
| `date` | 評価日 | 詳細の概要テーブル |
| `sagyoubi` | 作業日 | 詳細の概要テーブル |
| `fee` | 料金 | 詳細の概要テーブル（カンマを自動付与） |
| `rating_reception` ほか7項目 | 各評価 | 詳細の「項目別のご評価」 |
| `good` / `bad` | 良かった点 / 悪かった点 | 詳細 |
| `message` | メッセージ | 「なにわ引越センターより」の返信 |

`rating` が空の場合は `rating_total`（満足度）、それも空なら
値の入っている評価軸の平均を使います。

ACF が無効な環境では、テーマが簡易的な入力欄を代わりに表示します。

## 4. フォーム

### 求人応募フォーム

**外観 → カスタマイズ → なにわ：フォーム設定** に Contact Form 7 等の
ショートコードを貼り付けると、求人ページのフォームがそれに置き換わります。
空欄のあいだはデザイン確認用のダミーフォームが表示されます（送信はされません）。

### web見積フォーム（STEP1〜7）

テーマ内で完結しています。Contact Form 7 等のプラグインは不要です。

- 送信先は WordPress 標準の `admin-post.php` に固定しています。
  ページURLへ直接 POST するとサーバー側で弾かれる環境があるためです
- 入力内容はサーバー側（トランジェント、3時間保持）に保存し、
  処理後は次のステップへリダイレクトします（POST/Redirect/GET）。
  再読み込みしても再送信になりません
- 確認画面で入力内容を一覧表示し、「修正する」で各ステップへ戻れます（入力内容は保持されます）
- STEP6（荷物情報）は82項目を1ページにまとめ、カテゴリ内リンクで移動できます
  （スラッグは既存ページとの衝突を避けるため `estimate-items`）

送信すると、次の3つが実行されます。

1. **管理者宛メール**（設定 → 一般 の管理者アドレス。Reply-To はお客様のアドレス）
2. **お客様宛の自動返信メール**（入力内容の控え付き）
3. **送信内容をDBに保存**（管理画面「web見積の送信」に一覧表示）

管理者の宛先を変えたい場合：

```php
add_filter( 'naniwa_estimate_mail_to', function () {
	return 'info@naniwa-h.com';
} );
```

自動返信の件名・本文を変えたい場合：

```php
add_filter( 'naniwa_estimate_autoreply_subject', function ( $subject ) {
	return '【なにわ引越センター】お見積りを承りました';
} );

add_filter( 'naniwa_estimate_autoreply_body', function ( $body, $name, $detail ) {
	return $body;
}, 10, 3 );
```

> **スパム対策はテーマに含めていません。** 本番では Cloudflare 側で対応する前提です。
>
> **本番前に必ず実機でテスト送信してください。** レンタルサーバーによっては
> `wp_mail()` が届かないことがあるため、WP Mail SMTP などの導入を推奨します。

### 送信内容の保存

管理画面の **web見積の送信** に、受信日時・お名前・電話番号・メールアドレス・
ご希望プラン・**メール送信の成否**が一覧で表示されます。
詳細を開くと入力内容の全文が読めます。

新規追加はできない設定にしてあります（フォーム経由でのみ増えます）。
不要になったものは通常どおり削除できます。

### 自動返信が届かないとき

送信の記録を開くと、右側に **「メールの送信結果」** が出ます。

| 表示 | 意味 | 対処 |
|---|---|---|
| ✓ 送信 | WordPress からは正常に送られています | 迷惑メールフォルダを確認。それでも無ければ SMTP／DNS（SPF・DKIM）側の問題です |
| ✗ 失敗 ＋ 赤いエラー文 | 送信そのものが失敗しています | エラー文の内容を確認（多くは SMTP の認証エラーか宛先拒否） |
| — | 記録なし | この機能を入れる前の送信です |

同じ画面の **「お客様へ自動返信を再送する」** で、設定を直したあとに
同じ内容をもう一度送れます。フォームを入力し直す必要はありません。

### 管理者宛・自動返信の「両方」が失敗しているとき

サイト全体のメール送信が止まっています。テーマではなく WP Mail SMTP 側の問題で、
CF7 など他のプラグインからも同じように送れない状態です。

- `SMTP Error: Could not authenticate.`
  … SMTPのログインに失敗しています。**設定 → 一般 でパスワードを入力し直す**（上の⑥参照）。
  サーバーへの接続自体はできているので、ポートやファイアウォールは関係ありません
- `Could not connect to SMTP host`
  … ホスト名・ポート・暗号化方式が違うか、サーバーが外部への送信を塞いでいます
- `Do Not Send` が有効
  … 設定 → 一般 → その他 で送信が無効化されています

### 管理者宛は届いて自動返信だけ届かないとき

原因はほぼ次のどれかです。

1. **迷惑メール判定** … 送信元ドメインの SPF／DKIM が未設定だと、
   自社宛（同一サーバー内）は届いても外部宛が弾かれます
2. **WP Mail SMTP の送信元アドレス** … 「From Email」が実在しない
   アドレスだと、プロバイダ側で拒否されます。独自ドメインの実在する
   アドレス（例：`info@naniwa-h.com`）を指定してください
3. **送信数の上限** … 短時間に複数通送ると2通目だけ弾かれることがあります

WP Mail SMTP の **メールログ**（Email Log）を有効にしておくと、
プラグイン側から見た送信結果も残るので原因を切り分けやすくなります。

## 5. 見積CTAを出さないページ

求人ページと見積フォーム内では、フッター上の見積CTA帯とスマホ固定バーを非表示にしています。
他のページも同様にしたい場合は、フィルターでスラッグを追加してください。

```php
add_filter( 'naniwa_no_estimate_cta_slugs', function ( $slugs ) {
	$slugs[] = 'company';
	return $slugs;
} );
```

## 6. ファイル構成

```
naniwa-express/
├── style.css                  テーマ情報（実CSSは assets/css/style.css）

├── header.php / footer.php    共通ヘッダー・フッター
├── front-page.php             TOP
├── page-{slug}.php            固定ページ（スラッグで自動割り当て）
├── home.php / single.php      ブログ一覧・詳細
├── archive-voice.php / single-voice.php   お客様の声
├── archive-topics.php / single-topics.php  お知らせ
├── archive.php / search.php / 404.php / page.php
├── inc/
│   ├── setup.php              初期設定・診断画面
│   ├── page-map.php           固定ページの割り当て解決
│   ├── pages.php              必要な固定ページ一覧（自動生成）
│   ├── cpt.php                カスタム投稿タイプ（voice / topics / estimate）
│   ├── meta-voice.php         お客様の声の入力欄（ACF非導入時のみ）
│   ├── voice-fields.php       お客様の声のフィールド取得
│   ├── template-tags.php      テンプレート用ヘルパー
│   ├── estimate-fields.php    見積フォームの項目定義（自動生成）
│   └── estimate.php           見積フォームの送信処理
└── assets/                    CSS / JS / 画像
```

## 7. デザインを更新するとき

このテーマは静的サイトのソース（`src/`）から自動生成しています。
デザインを変えるときは静的側を直してから再生成してください。

```bash
python3 tools/build.py        # 静的サイトを再ビルド
python3 tools/build_theme.py  # テーマと ZIP を再生成
```

`inc/estimate-fields.php` と `page-*.php` は自動生成物です。直接編集しても
次回の再生成で上書きされます。

## 8. ナビゲーションの編集について

ドロワーメニューとフッターのリンクは、アイコン付きの独自マークアップのため
`header.php` / `footer.php` に直接記述しています。項目を増減するときは
静的サイトの `src/partials/` を編集して再生成してください。
